# Airline Sentiment Analysis Dashboard🪽

Hey there! 👋 This is an end-to-end machine learning project that takes customer airline reviews, digs into the data, and predicts sentiment on the fly. I built this to bring EDA, model training, and a live web app together into one smooth dashboard, And lastly with love❤️.

## What's in the App?
* **Past (EDA):** A look into the historical data, ratings distribution, and trends hiding inside customer feedback.
* **Present (Model Performance):** A side-by-side comparison of Logistic Regression and Random Forest models, showing their accuracy scores and confusion matrices.
* **Future (Live Predictor):** The best part—type any custom text or review into the box, hit predict, and watch the model instantly tell you if the vibe is Positive, Neutral, or Negative with confidence percentages🥹🥹

## Built With
* Python
* Streamlit 
* Pandas & Matplotlib
* Scikit-Learn
